# 🏡 نظام محاضر لجان بيع المزارع والميزان (PWA + ربط ثنائي مع الإكسيل)

تطبيق ويب تقدمي متكامل (**Offline-First Modular PWA**) لإدارة محاضر لجان بيع المزارع السمكية/الزراعية وموازين السيارات على مدار **10 أيام** لكل دورة، مع **ربط ثنائي الاتجاه (Two-Way Sync)** مع شيت الإكسيل المكون من **15 شيت بالمعادلات والتنسيقات الكاملة** ومزامنة سحابية لحظية حية.

## 📁 هيكلة ملفات المشروع المحدثة (v27 - الهيكل المفصول)
1. **`index.html`**: هيكل الصفحة الأساسي فقط (HTML5) مربوطاً بـ `./style.css` و `./app.js`.
2. **`style.css`**: ملف التنسيقات المفصول بالكامل (قواعد العرض المتجاوب للموبايل والكمبيوتر وتنسيقات الجداول).
3. **`app.js`**: المنطق البرمجي الكامل للنظام (المحرك المحاسبي، الميزان، المزامنة السحابية، محرك فلاتر الإكسيل، ومحرك تصدير/استيراد شيت الإكسيل ذي الـ 15 شيت).
4. **`sw.js`**: ملف الـ Service Worker (`farm-sales-committee-v27`) للعمل بدون إنترنت وتخزين ملفات الهيكلة الجديدة (`./index.html`, `./style.css`, `./app.js`).
5. **`manifest.json`** + **`icon-192.png`** + **`icon-512.png`**: ملفات تثبيت التطبيق كـ PWA مستقل على الموبايل والكمبيوتر.
6. **`HANDOVER_TECHNICAL_SUMMARY.md`**: وثيقة الملخص التقني الشامل للمشروع.
7. **`نظام_محاضر_بيع_مزرعة_ابوذكري_10_ايام.xlsx`**: شيت الإكسيل المرجعي (15 شيت بالمعادلات).
8. **`نظام_مبيعات_مزرعة_أبوذكري.html`**: نسخة احتياطية مدمجة في ملف واحد للاستخدام المحلي المستقل.
