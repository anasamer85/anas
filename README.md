# نظام محاضر لجان بيع المزارع (PWA + يعمل بدون إنترنت + ربط ثنائي مع الإكسيل + مزامنة سحابية حية)

## محتويات الحزمة الكاملة للمشروع (هيكلة الملفات المتعددة):
1. `index.html` : هيكل الصفحة الأساسي (HTML5 DOM Structure) ويربط ملفات التنسيق والبرمجة الخارجية.
2. `style.css` : ملف التنسيقات المستقل للهوية البصرية وتنسيقات الجداول المتجاوبة للموبايل والكمبيوتر.
3. `app.js` : المنطق البرمجي الكامل للمنظومة (6,875 سطر برمجي غير مختصر)، يضم المحرك المحاسبي، محرك الربط الثنائي مع الإكسيل (15 شيت بالمعادلات والتنسيقات)، محرك المزامنة السحابية الحية، نظام المستخدمين والصلاحيات، ومحرك الفلترة والفرز الشبيه بالإكسيل لجميع الجداول الـ 10.
4. `sw.js` : محرك العمل بدون إنترنت (Service Worker - الإصدار `farm-sales-committee-v18`)، يخزن `index.html` و `style.css` و `app.js` وباقي الأصول، مع استثناء روابط السحابة من الكاش.
5. `manifest.json` : ملف تعريف تطبيق الويب التقدمي (PWA) لتثبيت الموقع كتطبيق مستقل على الموبايل (Android / iOS) والكمبيوتر.
6. `icon-192.png` & `icon-512.png` : أيقونات التطبيق الرسمية للموبايل وسطح المكتب.
7. `نظام_محاضر_بيع_مزرعة_ابوذكري_10_ايام.xlsx` : قالب ملف الإكسيل القياسي المكون من 15 شيت بالمعادلات والتنسيقات.
8. `نظام_مبيعات_مزرعة_أبوذكري.html` : نسخة أرشيفية مدمجة للاستخدام المحلي المنفرد.
9. `HANDOVER_TECHNICAL_SUMMARY.md` : وثيقة الملخص التقني الشامل المحدثة بهيكلة الملفات المتعددة.
