# 🏡 نظام محاضر لجان بيع المزارع والميزان (PWA + ربط ثنائي مع الإكسيل — الإصدار v49)

تطبيق ويب تقدمي متكامل (**Offline-First Modular PWA**) لإدارة محاضر لجان بيع المزارع السمكية/الزراعية وموازين السيارات على مدار **10 أيام** لكل دورة، مع **ربط ثنائي الاتجاه (Two-Way Sync)** مع شيت الإكسيل المكون من **15 شيت بالمعادلات والتنسيقات الكاملة** ومزامنة سحابية لحظية حية.

## 📁 هيكلة ملفات المشروع المقسمة (v49 - الهيكل المفصول الصارم)
1. **`index.html`**: هيكل الصفحة الأساسي فقط (HTML5) مربوطاً بـ `./style.css` و `./app.js`.
2. **`style.css`**: ملف التنسيقات المفصول بالكامل (قواعد العرض المتجاوب للموبايل والكمبيوتر وتنسيقات الجداول والطباعة الحرارية والرسمية).
3. **`app.js`**: المنطق البرمجي الكامل للنظام بدون أي اختصار (المحرك المحاسبي، الميزان، المزامنة السحابية المضادة للاختراق، التحكم في إظهار/إخفاء بيانات الرقابة، محرك فلاتر الإكسيل، ومحرك تصدير/استيراد شيت الإكسيل ذي الـ 15 شيت مع منع التكرار المزدوج وتنظيف البيانات).
4. **`sw.js`**: ملف الـ Service Worker (`farm-sales-committee-v49-audit-diff-and-day-lock`) للعمل بدون إنترنت وتخزين ملفات الهيكلة المقسمة (`./index.html`, `./style.css`, `./app.js`).
5. **`manifest.json`** + **`icon-192.png`** + **`icon-512.png`**: ملفات تثبيت التطبيق كـ PWA مستقل على الموبايل والكمبيوتر.
6. **`HANDOVER_TECHNICAL_SUMMARY.md`**: وثيقة التسليم التقنية الشاملة والنهائية للمشروع (`v49`).

## 🛡️ ملخص التحديثات الجوهرية في الإصدار `v49`

1. **محرك المزامنة السحابية المضاد للاختراق (`Bulletproof Offline-First Sync Engine`):**
   - معايرة فرق التوقيت مع السحابة (`calibrateCloudClockOffset` و `getSyncedNow`) مع هامش تسامح `60 دقيقة` (`CLOCK_SKEW_BUFFER_MS`).
   - الدمج الذري لأيام المزرعة (`mergeDaysObjects`) ولأرشيف المزارع (`mergeFarmSnapshots`) ببنية `OR-Set` مع الحماية التامة ضد الـ 0 حركات أو المسح العكسي.
   - تطهير سجل المحذوفات (`deletedIds` و `deletedTimestamps`) عبر `sanitizeMergedTombstonesAgainstLiveData` مع تقليم تلقائي (`Garbage Collection`) لأقدم المعرفات لمنع امتلاء `LocalStorage`.

2. **التحكم في إظهار وإخفاء بيانات الرقابة الزمنية (`Audit Metadata Visibility Toggle`):**
   - زر تبديل تفاعلي داخل قسم `🕵️ سجل الرقابة الزمني لحركات المندوبين (Audit Trail)` في لوحة التحكم لإظهار أو إخفاء النصوص التفصيلية أسفل الحركات (`👤 مدير الموقع | 🕒 01:39 ص`) مع حفظ التفضيل تلقائياً في `LocalStorage`.

3. **تحصين تكامل ملفات الإكسيل (`Excel Integration QA & Fortification`):**
   - منع التكرار المزدوج عند تحديث الموقع من نفس ملف الإكسيل أو عبر الربط المباشر باستخدام المفاتيح المركبة (`excelCompositeKey`) ودالة `isSaleRecordUnchanged` مع الحفاظ على الـ `UUID` الأصلي وبيانات الرقابة.
   - تنظيف شامل للبيانات القادمة من الإكسيل (`sanitizeExcelText`, `normalizeArabicMerchantCompareKey`, `sanitizeExcelPositiveIntOrEmpty`, `extractCustodyAndCleanNotesFromExcel`) ودعم المصروفات غير المصنفة (البند التاسع في `5_ملخص_المصروفات`).
