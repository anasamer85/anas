# نظام محاضر لجان بيع المزارع (PWA + يعمل بدون إنترنت + ربط ثنائي مع الإكسيل)

## محتويات الملف المضغوط (جميع ملفات الموقع المحدثة):
1. `index.html` : الملف الرئيسي للموقع والمنظومة (شامل جميع التحديثات: عرض الجداول بالكامل بدون شريط تمرير أفقي، زر تفعيل/إخفاء الفلاتر الاختياري بجانب البحث السريع، الملخص التنفيذي للأيام النشطة، وتثبيت الكود الموحد للتجار).
2. `manifest.json` : ملف تعريف تطبيق الويب التقدمي (PWA) لتثبيت الموقع كتطبيق مستقل على الموبايل والكمبيوتر.
3. `sw.js` : محرك العمل بدون إنترنت (Service Worker - الإصدار v9) لحفظ ملفات النظام والعمل أوفلاين.
4. `icon-192.png` & `icon-512.png` : أيقونات التطبيق للموبايل وسطح المكتب.
